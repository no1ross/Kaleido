# Kaleido.Http

Kaleido HTTP API shape shared by the HTTP server (Kaleido.Http.Server), the HTTP clients (Kaleido.Http.Client) and the registry's HTTP API: the route paths, URLs and endpoint names.

See the [repository README](https://github.com/no1ross/Kaleido#readme) and [ARCHITECTURE.md](https://github.com/no1ross/Kaleido/blob/master/ARCHITECTURE.md).
