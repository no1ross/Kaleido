# Kaleido.Client (unmigrated source)

This old preview project is a parked migration source, not the owner of Process or Queryable outbound client contracts. Neutral Process client/factory contracts now belong to [`Kaleido.Process.Client`](../Capabilities/Process/Kaleido.Process.Client/README.md); the Process HTTP implementation is a separate later owner (#622). It is **not** the active Registry participant or the owner of Queryable's neutral remote-client API. The Registry participant and its hydrated unfiltered in-memory source now live in [`Kaleido.Registry.Client`](../Capabilities/Registry/Kaleido.Registry.Client/README.md); the shared outbound HTTP call-purpose, credential and correlation mechanics live in [`Kaleido.Http.Client`](../Transports/Http/Kaleido.Http.Client/README.md).

`IKaleidoQueryableClient` and its factory are being moved to [`Kaleido.Queryable.Client`](../Capabilities/Queryable/Kaleido.Queryable.Client/README.md), taking generic `QueryRequest` instead of an HTTP request DTO. The actual HTTP adaptation and lookup of published Registry bindings live in [`Kaleido.Queryable.Http.Client`](../Capabilities/Queryable/Kaleido.Queryable.Http.Client/README.md) (#616). Old combined HTTP/Platform dependents remain parked under #585; do not build this source project to validate the independent Process or Queryable neutral contract units or reintroduce a Registry/Platform dependency into them.
