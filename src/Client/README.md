# Kaleido.Client

Kaleido client base, with no ASP.NET Core: the processor and queryable client contracts libraries call, and what a call made for a caller is (call context, purpose, on-behalf-of modes).

See the [repository README](https://github.com/no1ross/Kaleido#readme) and [ARCHITECTURE.md](https://github.com/no1ross/Kaleido/blob/master/ARCHITECTURE.md).
