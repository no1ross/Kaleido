# Composition area rules

Inherit root and `src/` guidance. A composed host calls each owner registration with its own validated options; `AddKaleido()` remains foundation-only. Transport-neutral `Kaleido.Hosting` must work for a generic/console relay host as well as future HTTP hosting and must not depend on ASP.NET or a nonexistent gRPC implementation. The Hosting provider check examines final DI registrations and reports missing required Process/Eventing stores; any registered implementation, including explicitly chosen in-memory, is valid. Do not introduce hidden provider selection, reverse project references or duplicate capability/authorization policy. Consult [dependency boundaries](../../docs/architecture/dependencies.md), the owner README/AGENTS files and affected integration fixtures when composition is implemented; no fake no-op `AddGrpcHosting()`.
