# Kaleido.Provider.InMemory

Explicit local/test implementations of the existing Process state, Process.Server idempotency-admission and Eventing outbox store contracts. This package references the base [`Kaleido.Provider`](../Kaleido.Provider/README.md) dependency bundle. The three real in-memory stores and their behavior tests live here, not in lower capability projects. No provider is silently selected by `AddKaleido()`, `AddProcess()` or `AddEventing()`.

Call `AddInMemoryProviders()` to select all three stores or `AddInMemoryContextProvider()`, `AddInMemoryOutboxProvider()` and `AddInMemoryIdempotencyProvider()` individually when only one or two need memory. A host explicitly chooses **one provider per store**. Registering the same memory choice twice is idempotent; choosing SQLite, another durable implementation or a host-supplied store for the same contract in either order fails with `conflicting_store` (outbox: `conflicting_outbox`). An aggregate memory choice detects every conflict before registering any of its stores. `Kaleido.Hosting` checks only that the stores used by the host are registered; a console Process host need not install a server-side idempotency store unless it serves that capability.

Each memory store is a singleton per host: state, replay/admission fences and queued events remain visible across request scopes. Each emits a **Warning when constructed** that its records are lost on restart and not shared between service instances. The memory choice offers no shared state/event transaction; production hosts choose durable stores that participate in one provider session instead. A control Registry may explicitly use its own Registry.Server in-memory store; this package does not register the Registry authority or its store. See [ADR 0049](../../../docs/decisions/0049-one-provider-per-store.md), [persistence guide](../../../docs/guide/persistence.md) and the [composed-host functional test](../../../tests/Providers/Kaleido.Provider.InMemory.FunctionalTests/InMemoryProviderHostFunctionalTests.cs).
