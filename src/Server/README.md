# Former Server project location

The transport-neutral `Kaleido.Server` project and its authorization settings now live at [src/Transports/Kaleido.Server](../Transports/Kaleido.Server/README.md). Its former ASP.NET caller, authorization, JSON and endpoint-filter implementations were Git-moved to the existing [HTTP server project](../Transports/Http/Kaleido.Http.Server/README.md), where generic ASP.NET mechanics are being reconciled. Central-registry-specific HTTP listeners and clients live in [Registry.Http.Server](../Capabilities/Registry/Kaleido.Registry.Http.Server/README.md) and [Registry.Http.Client](../Capabilities/Registry/Kaleido.Registry.Http.Client/README.md); local Process execution and Queryable source registration remain in their capability projects. No HTTP or central Registry behavior is registered by neutral Server.
