# MCP adapter rules

Inherit root and `src/` guidance. MCP exposes caller-filtered registry capabilities and guided continuation, not transport-neutral Process/Queryable execution or business decisions. Preserve authenticated caller identity, token exchange and authorization filtering across the tool boundary; never copy or log inbound credentials. A tool's process id is a handle, not an authorization decision. Read the [MCP README](Mcp/README.md), [authorization threat model](../../docs/architecture/authorization.md#threat-model-the-process-id-is-a-bearer-handle) and [correlation flow](../../docs/architecture/correlation.md) before changing invocation. MCP has not completed its #585 project migration: update matching functional/unit tests and docs when that area is reached.
