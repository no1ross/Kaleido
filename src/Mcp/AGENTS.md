# MCP adapter rules

Inherit root and `src/` guidance. MCP exposes caller-filtered registry capabilities and guided continuation, not transport-neutral Process/Queryable execution or business decisions. Preserve authenticated caller identity, token exchange and authorization filtering across the tool boundary; never copy or log inbound credentials. A tool's process id is a handle, not an authorization decision. Read the [MCP README](Mcp/README.md), [authorization threat model](../../docs/architecture/authorization.md#threat-model-the-process-id-is-a-bearer-handle) and [correlation flow](../../docs/architecture/correlation.md) before changing invocation. MCP uses the validated `AddKaleido()` `ServiceName`/`ServiceVersion` for its initialize identity; do not add separate MCP name/version settings or reinterpret Registry `BuildVersion` as the service version (ADR 0051). MCP-owned settings implement `IKaleidoOptions` and use `builder.BindOptions()` with a snapshot of mutable inputs. Update matching functional/unit tests and docs when changing this owner; the full #585 solution gate remains pending.
