# Observability area rules

Inherit root and `src/` guidance. This area owns opt-in telemetry SDK/export wiring, not the Process, Queryable or Eventing behavior that emits measurements. Before changing subscriptions or copied instrument names, read the owning capability's `*Telemetry` definitions and [dependency model](../../docs/architecture/dependencies.md); keep shared names and tag values compatible. Do not put an OpenTelemetry SDK dependency into Kaleido foundation or a capability. `Kaleido.Observability.OpenTelemetry` references the Eventing, Process and Queryable owners whose telemetry names it subscribes to. Keep the SQLite and MCP names copied locally rather than adding provider/adapter dependencies. Run its own targeted build/tests, not the final pack gate, when changing subscriptions.
