# HTTP transport rules

Inherit root, `src/` and `src/Transports/` guidance. `Kaleido.Http` now lives here and owns shared HTTP JSON, headers, structured errors and versioned route-prefix mechanics, **without** a Platform, capability, central Registry or ASP.NET reference. Process/Queryable/Registry URLs and requests belong to their own `.Http` projects. `Kaleido.Http.Server` owns generic ASP.NET filters, correlation, authorization and body binding without Platform, capability or central Registry project references. Its filters apply only to Kaleido route groups, never host-wide JSON/auth/error behavior. `Http.Client` remains under `src/Http/` until its project unit. Read [HTTP boundaries](../../../docs/architecture/transports/http.md) and affected READMEs before changing the seam; move matching fixtures and update docs with each owner. Neutral Server must not implement HTTP behavior.
