# HTTP transport rules

Inherit root, `src/` and `src/Transports/` guidance. `Kaleido.Http` now lives here and owns shared HTTP JSON, headers, structured errors and versioned route-prefix mechanics, **without** a Platform, capability, central Registry or ASP.NET reference. Process/Queryable/Registry URLs and requests belong to their own `.Http` projects. The legacy Http.Server/Http.Client projects remain under `src/Http/` until their project units; do not move them merely to fill this area. Their ASP.NET filters apply only to Kaleido route groups, never host-wide JSON/auth/error behavior. Read [HTTP boundaries](../../../docs/architecture/transports/http.md) and affected READMEs before changing the seam; move matching fixtures and update docs with each owner. Neutral Server must not implement HTTP behavior.
