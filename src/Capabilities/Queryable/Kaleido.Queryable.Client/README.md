# Kaleido.Queryable.Client

This package owns the **transport-neutral outbound Queryable client contracts**: `IKaleidoQueryableClient` and the service-name/version-pinned `IKaleidoQueryableClientFactory`. A consumer names a remote source or view and passes generic Queryable's `QueryRequest` / `QueryRequest<TParameters>`; it receives `QueryResult<T>`. These are the same neutral query shapes local sources use, not HTTP `QueryApiRequest` or transport JSON values. The old wire-only client signatures move during the #585 preview under [#615](https://github.com/no1ross/Kaleido/issues/615) and the decision for HTTP conversion belongs to [#616](https://github.com/no1ross/Kaleido/issues/616).

This contracts-only assembly references generic [`Kaleido.Queryable`](../Kaleido.Queryable/README.md), not Platform, Registry.Server, ASP.NET, HTTP or gRPC. It has no network implementation or implicit registration. The real HTTP factory/client will live in `Kaleido.Queryable.Http.Client`; it will resolve each call against the participant's hydrated **unfiltered** Registry, choose the published version and source/view binding, and convert the neutral request through [`Kaleido.Queryable.Http`](../Kaleido.Queryable.Http/README.md). Local `AddQueryable()` does not require Registry participation or an outbound client.
