# Registry capability rules

Inherit root, `src/` and `src/Capabilities/` guidance. Shared `KaleidoAuthorizationAttribute` and `AuthorizationMetadata` now live in Core's `Registry/` folder and `Kaleido.Registry` namespace; Process and Queryable may depend on Core but never on the central control-registry implementation. This area is reserved for the later control-registry migration: keep its store/lease/cache/aggregation work distinct from local Process and Queryable registries, decide its dependencies against the actual [graph](../../../docs/architecture/dependencies.md), and move its existing project with Git history when reached. Do not recreate a no-op Registry.Next shell or make Core depend upward. Read [authorization](../../../docs/architecture/authorization.md) before changing declarations or their public namespace; keep fixtures with the owning project.
