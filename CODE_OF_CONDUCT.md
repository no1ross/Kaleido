# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone in the project's spaces: issues, pull requests,
reviews and discussions.

In short: be respectful and constructive, assume good intent, critique ideas rather than people,
and do not harass anyone.

**Reporting.** Report unacceptable behavior privately to the maintainer,
[@no1ross](https://github.com/no1ross), on GitHub. Reports are kept confidential. The maintainers
decide on the consequences described in the Covenant's enforcement guidelines.
