# Kaleido Brand Guide

## Brand idea

**Kaleido** turns business capabilities into typed, discoverable building blocks. The faceted **K** reflects composition, multiple perspectives, and the way structured metadata can be assembled into a coherent system.

**Tagline:** `Typed. Discoverable. Stateful.`

**Positioning statement:** A .NET framework for exposing typed queries and stateful business processes as machine-discoverable HTTP capabilities.

## Typography

Use **Inter** when it is available. Fall back to **Segoe UI**, **Arial**, and `sans-serif`. Use a restrained monospace face for source code only. No font files are included in this kit.

## Voice

Kaleido should sound:

- Clear rather than clever
- Technical without being academic
- Confident without claiming production guarantees that have not been demonstrated
- Focused on consumer outcomes rather than internal architecture
