1. Core Requirements

Build a metadata-driven ASP.NET Core surface for Queryable that is:

Self-describing.
Discoverable from a root catalog endpoint.
Independent of internal runtime/registry implementation details.
Suitable for future OpenAPI generation.

Ensure consumers can fully navigate the API from metadata:

Discover records.
Discover record metadata.
Discover named queries.
Discover named query metadata.
Execute queries.

Verify ASP.NET route registration with unit tests.

Explicitly validate route registration behavior.
Protect against accidental breakage years later.
Exercise internal/private traversal paths through public APIs.

Prepare for future adapters:

Queryable.AspNetCore
Queryable.OpenApi
Queryable.Grpc

Avoid premature creation of:

Kaleido.AspNetCore
Shared ASP.NET abstractions
Common infrastructure projects unless actual reuse emerges.

MapPost()

functional-records/query

QueryableContractUrls

Used by:

MetadataUrl
QueryUrl
ExecuteUrl

Endpoint Names

NamedQueryEndpointName(...)

Protect OpenAPI operation naming later.
