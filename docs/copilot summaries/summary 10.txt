1. Core Requirements

Build a metadata-driven process framework, not a workflow engine.

Build a framework/runtime first, not an API.

API, UI, agents, batch jobs, and services should all be consumers of the same runtime.

The core runtime question is:

Given everything I know right now, what am I allowed to do next?

The framework must:

Track accumulated process context.
Determine available operations dynamically.
Return required attributes for each available operation.
Execute business operations.
Update context.
Re-evaluate available operations after execution.

The framework must support:

Non-linear process progression.
Dynamic branching.
Repeated operations.
Context-driven operation availability.

The process model must support:

A → B or C or D → E or B or C


rather than:

A → B → C → D


Business operations may:

Call external services.
Perform validations.
Perform lookups.
Enrich context.
Determine future operation availability.

Product/domain teams must retain ownership of business behavior.

A common framework team may own the runtime/coordinator.

The framework must avoid becoming another enterprise monolith.

Process
    ↓

Process Coordinator

Responsibilities:

Coordinate requests.
Discover participants.
Build metadata catalog.
Resolve participant ownership.
Route operations.
Aggregate responses.
Return process state.

Explicitly does NOT own:

Product-specific business rules.
Product-specific operation availability logic.
Product-specific validations.
Process Participants

Responsibilities:

Own business process behavior.
Expose metadata.
Expose capabilities.
Expose operations.
Evaluate operation availability.
Execute operations.
Return updated process responses.

Examples conceptually:

Radiology Participant
Transportation Participant
RBM Participant
Rehab Participant


Participants are logical contributors to a process.

Capabilities

Current role:

Logical grouping construct.
Organizes related operations.
Not directly executed by consumers.

Example:

    SelectMember

Procedure Capability
    SearchProcedure
    SelectProcedure

Submission Capability
    SubmitRequest
